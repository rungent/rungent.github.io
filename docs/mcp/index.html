MCP adapter

Expose the same typed Agent tools to an external MCP client.

Mount rungent.mcp.create_mcp_asgi next to the product FastAPI router. The adapter invokes @tool functions directly. It does not start a Runtime session, emit ACS events, or run the model loop.

Use the same Agent and the same @tool implementations. Pass tools= when the external catalog must be a subset (hide open_page and every requires_interaction_response continuation).

Unauthenticated POST /mcp returns 401 with WWW-Authenticate: Bearer … resource_metadata="…". OAuth discovery and login belong to the host application. See External agents.

Agent.export_skill() writes a SKILL.md draft from exportable tools. Rewrite the voice and auth steps in the host product; do not ship the in-app system prompt as a Skill.
